Ledgerstone support

Send us a message and include your Jira site address (for example, yourcompany.atlassian.net).

We use your name, email and message only to answer you. The form goes through Cloudflare, which checks that you are not a bot, and Postmark, which delivers it to us. Privacy Policy

Prefer email, or want to send a screenshot? Write to support@monaidea.com.

Before you write

  • Opening the app: a Jira administrator opens it from Jira settings → Apps → Ledgerstone.
  • Missing or "unknown" results: click Run snapshot now on the Overview.
  • What it changes: nothing. Ledgerstone only reads Jira; it never changes permissions, schemes, groups or users.

Please never send

Passwords, API tokens or exports of your user list. We will never ask for them.
